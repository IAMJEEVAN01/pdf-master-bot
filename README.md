# PDF Master Bot

All-in-one Telegram bot for PDF tools with premium system.

## Features
- Merge, Compress, Split, Rotate PDFs
- Password Protect
- Organize pages
- Image to PDF
- Premium system
- Force join
- Logs channel

## Environment Variables
- `API_ID`
- `API_HASH`
- `BOT_TOKEN`
- `SESSION_STRING`
- `LOGS_CHANNEL_ID`
- `OWNER_ID`

## Deploy on Koyeb
1. Push to GitHub
2. Create service on Koyeb
3. Select repo
4. Add environment variables
5. Deploy
